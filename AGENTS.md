This is a Godot 4.7 game called Job Simulator 2.

- GDScript, 3D scenes built mostly in code, low-poly GLB assets in assets/models/
- Refactor rather than duplicating code
- Keep scripts small and focused, one job per file in scripts/jobs/
- Goal is an A+ codebase, not a pile of scenes
- Verify changes with `godot --headless --import` and `godot --headless -s tools/smoke_test.gd`
- Assets are generated by tools/make_assets.py, run it through Blender headless to rebuild them
